# create-mfeflow

Part of [mfeflow](https://github.com/mfeflow/mfeflow), the React micro-frontend boilerplate and platform kit.

```sh
npm create mfeflow@latest my-app -- --yes
```

This is `mfeflow init` with the same arguments, so every flag of
[`mfeflow init`](https://github.com/mfeflow/mfeflow/tree/main/packages/cli#readme) works here
(`--scope`, `--remotes`, `--features`, `--preset`, `--dry-run`, `--json`, `--local`, ...).

Pre-1.0: flags and templates may change in minor versions.
