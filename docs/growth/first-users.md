# First users

Notes from people who tried mfeflow. We keep them because the Phase 13 gate counts people who ran `npm create mfeflow` and told us how it went, and we cannot count what we did not write down.

This file is not linked from the docs site. It is for the maintainers.

## Rules

- Use a handle only if the person said it is fine. Otherwise write "a developer at a small company" or similar.
- Quote their words as they wrote or said them. Do not tidy them.
- Write what broke even when it was our mistake. That is the point of the file.
- Link the issue, discussion or pull request if there is one.
- If we talked to twenty people and none of them tried it, write the reason here before adding any feature.

## Format

Add new entries at the top of the Entries section, newest first. Copy this block:

```md
### 2026-MM-DD, handle or description

- Who: handle (with their OK), or a description
- What they tried: the command or the goal, and how far they got
- What broke: the error, the confusing page, or "nothing"
- Their words: "quote"
- What we changed: link to the issue or pull request, or "nothing yet"
```
