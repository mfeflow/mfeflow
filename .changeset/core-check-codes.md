Error codes for `mfeflow doctor`, `budget` and `dev`: `E111` to `E117` (workspace package without a version, app missing on disk, invalid `mfe.json`, registry entry, shared port, route or name clash, copied file changed) and `E301` to `E306` (singleton versions, remote not compatible, runtime plugin imports a shared module, bundle over budget, no build output, dev server could not start). Each has a docs page.
