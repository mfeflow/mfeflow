# MFEFLOW_E604

Files you changed need a decision.

## What you see

```
MFEFLOW_E604 Files you changed need a decision: 2 not decided: env.ts, apps/shell/src/pages/Home.tsx
```

`mfeflow upgrade` found files that you changed and that the new version also wants to change. It never overwrites those on its own. Without a terminal to ask in, it stops before writing anything.

## Fix

Nothing was written. Run `mfeflow upgrade --dry-run` to see each diff, then pass --accept <path> to take the new version of a file, --keep <path> to keep yours, or `all` for every file.
