# MFEFLOW_E119

A runtime-config file does not match the runtime-config schema.

Each `public/config/runtime-config.<env>.json` must have every required key of `runtimeConfigSchema` in `src/config/schema.ts`, and no key the schema does not know. `mfeflow doctor` compares the keys; `pnpm check:runtime-config` validates the values with your validator before a deploy.

## Fix

Add or remove the keys, then run `pnpm check:runtime-config`.
