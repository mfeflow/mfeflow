# MFEFLOW_E118

.env.example does not match the keys in env.ts.

Every key of the `server` schema in env.ts belongs in .env.example, so a new developer sees what to set; a key that env.ts no longer has does not.

## Fix

Add the missing lines, or remove the stale ones. `mfeflow add env-key KEY --scope server --schema "…"` writes both places, and `mfeflow doctor` re-checks them.
