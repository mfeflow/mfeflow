# MFEFLOW_E310

A tool this command runs is not installed or not set up.

## Fix

Install the package the message names in the project (`pnpm add -D <package>`), or add the feature that sets it up (`mfeflow add testing`, `mfeflow add lint-oxlint`, `mfeflow add tsconfig`). mfeflow runs the project's own copy and never ships one.
