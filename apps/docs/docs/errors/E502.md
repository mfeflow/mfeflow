# MFEFLOW_E502

A route of this remote overlaps a route of another remote.

## Fix

Give each URL to one remote (/checkout/* also covers /checkout/pay), then deploy again. Nothing was uploaded. See https://mfeflow.github.io/mfeflow/guide/deploy-and-rollback.
