# Changelog

All mfeflow packages are released together under one version. The full notes for each release are in [packages/cli/CHANGELOG.md](packages/cli/CHANGELOG.md), every package has its own `CHANGELOG.md` next to it, and each release is on the [GitHub releases page](https://github.com/mfeflow/mfeflow/releases) with its tarballs and, from 0.9.0, a signed provenance file.

| Version | Date | Highlights |
| --- | --- | --- |
| [0.9.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.9.0) | 2026-11-07 | `mfeflow mcp`, a stdio MCP server for coding agents |
| [0.8.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.8.0) | 2026-11-06 | Vite as a second bundler; `init --kind remote`, `--kind tooling` and `--remotes none` |
| [0.7.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.7.0) | 2026-11-02 | `deploy-cloudflare` and `deploy-docker` features; `doctor --against` |
| [0.6.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.6.0) | 2026-11-02 | `mfeflow adopt`; `mfeflow.app.json`; `check-compat --against` a shell in another repo |
| [0.5.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.5.0) | 2026-11-01 | `mfeflow deploy`, `promote`, `rollback` and `status` on a static registry |
| [0.4.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.4.0) | 2026-11-01 | Third-party feature registries |
| [0.3.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.3.0) | 2026-11-01 | Nine features including `theming`, `i18n`, `tailwind`, `ui-shadcn` and `storybook` |
| [0.2.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.2.0) | 2026-11-01 | `event-bus`, `route-factory` and `http` features |
| [0.1.0](https://github.com/mfeflow/mfeflow/releases/tag/v0.1.0) | 2026-11-01 | First release: `init`, `add`, `dev`, `doctor` and `npm create mfeflow` |

Security fixes are listed in the release notes of the version that fixes them. To report a vulnerability, see [SECURITY.md](https://github.com/mfeflow/.github/blob/main/SECURITY.md).
